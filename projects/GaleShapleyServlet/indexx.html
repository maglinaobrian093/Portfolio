💘 Stable Match
System

An interactive simulation system that demonstrates how the Gale-Shapley Stable Matching Algorithm works in pairing two groups based on personality preferences.

Inspired by modern matching systems like Omegle and dating apps, this project visualizes how stable pairs are formed without conflicts or unstable matches.

🧠 About the Algorithm

The Gale-Shapley Algorithm is a famous algorithm used to solve the Stable Marriage Problem, first published in 1962 by David Gale and Lloyd Shapley.

One group proposes while the other group accepts or rejects proposals based on preferences until stable matches are formed. The result is always stable and optimal for the proposing group.
